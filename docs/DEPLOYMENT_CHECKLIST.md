## 部署步骤

### 1. 上传文件

```bash
# 使用 scp 上传
scp build/libs/rbac-system-1.0.0.jar user@server:/opt/rbac-system/
scp deploy/*.sh user@server:/opt/rbac-system/
scp application-prod.yml user@server:/opt/rbac-system/
```

- [ ] JAR 包已上传
- [ ] 启动脚本已上传
- [ ] 配置文件已上传
- [ ] 文件权限正确

### 2. 配置脚本权限

```bash
chmod +x /opt/rbac-system/*.sh
```

- [ ] 脚本可执行权限已设置

### 3. 启动应用

```bash
cd /opt/rbac-system
./start.sh
```

- [ ] 应用启动成功
- [ ] 进程正在运行
- [ ] 端口正在监听

### 4. 验证部署

```bash
# 检查进程
ps aux | grep rbac-system

# 检查端口
netstat -an | grep 8080

# 检查日志
tail -f logs/output.log
```

- [ ] 进程正在运行
- [ ] 端口正在监听
- [ ] 日志无错误
- [ ] 应用启动完成
