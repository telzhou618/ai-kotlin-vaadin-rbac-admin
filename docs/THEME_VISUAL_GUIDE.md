## 切换动画流程

```
步骤 1: 用户点击主题按钮
   [🌙] ← 点击
   
步骤 2: 主题立即切换
   页面背景从白色变为深色
   文字颜色从深色变为浅色
   
步骤 3: 按钮图标更新
   [🌙] → [☀️]
   
步骤 4: 完成
   用户可以继续使用系统
```

## 图标说明

| 图标 | 含义 | 使用场景 |
|------|------|----------|
| 🌙 | 月亮 | 当前为亮色模式，点击切换到暗色 |
| ☀️ | 太阳 | 当前为暗色模式，点击切换到亮色 |
| 🏠 | 首页 | 导航菜单 - 首页 |
| 👤 | 用户 | 导航菜单 - 用户管理 |
| 👥 | 角色 | 导航菜单 - 角色管理 |
| 🔒 | 权限 | 导航菜单 - 权限管理 |
| 📋 | 日志 | 导航菜单 - 操作日志 |
| ☰ | 菜单 | 展开/收起侧边栏 |
