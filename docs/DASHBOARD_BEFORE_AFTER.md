# Dashboard 优化前后对比

## 代码对比

### 优化前 ❌

```kotlin
horizontalLayout {
    width = "100%"
    
    div {
        width = "25%"
        element.style.set("padding", "20px")
        element.style.set("background", "#e3f2fd")  // 硬编码蓝色
        element.style.set("border-radius", "8px")
        h3("用户总数")
        h2(data.userCount.toString())
    }
    
    div {
        width = "25%"
        element.style.set("padding", "20px")
        element.style.set("background", "#f3e5f5")  // 硬编码紫色
        element.style.set("border-radius", "8px")
        h3("角色总数")
        h2(data.roleCount.toString())
    }
    
    // ... 更多重复代码
}
```

**问题：**
- ❌ 硬编码颜色值
- ❌ 暗色模式下不适配
- ❌ 代码重复
- ❌ 缺少图标
- ❌ 视觉层级不明显

### 优化后 ✅

```kotlin
// 统计卡片容器
val statsLayout = HorizontalLayout().apply {
    width = "100%"
    setSpacing(true)
}

// 用户统计卡片
statsLayout.add(createStatCard(
    title = "用户总数",
    value = data.userCount.toString(),
    icon = VaadinIcon.USER,
    colorTheme = "primary"
))

// 创建统计卡片方法
private fun createStatCard(
    title: String,
    value: String,
    icon: VaadinIcon,
    colorTheme: String
): Div {
    return Div().apply {
        // 使用 Lumo 工具类
        addClassNames(
            LumoUtility.Background.CONTRAST_5,  // 自动适配
            LumoUtility.BorderRadius.MEDIUM,
            LumoUtility.Padding.LARGE
        )
        
        // 使用 Lumo CSS 变量
        element.style.set("color", "var(--lumo-primary-color)")
    }
}
```

**优点：**
- ✅ 使用 Lumo 官方样式
- ✅ 自动适配明暗主题
- ✅ 代码复用
- ✅ 添加图标
- ✅ 清晰的视觉层级

## 技术细节对比

### 背景色

| 项目 | 优化前 | 优化后 |
|------|--------|--------|
| 实现方式 | `element.style.set("background", "#e3f2fd")` | `addClassNames(LumoUtility.Background.CONTRAST_5)` |
| 亮色模式 | 固定的浅蓝色 `#e3f2fd` | 自动计算的浅灰色 `rgba(0,0,0,0.05)` |
| 暗色模式 | 仍然是浅蓝色（不适配） | 自动计算的深灰色 `rgba(255,255,255,0.05)` |
| 可维护性 | 低（需要手动处理主题） | 高（自动适配） |

### 文字颜色

| 项目 | 优化前 | 优化后 |
|------|--------|--------|
| 标题 | 默认颜色 | `LumoUtility.TextColor.SECONDARY` |
| 数值 | 默认颜色 | 默认（自动适配） |
| 亮色模式 | 黑色 | 深灰色（更柔和） |
| 暗色模式 | 黑色（不可读） | 浅灰色（清晰可读） |

### 图标

| 项目 | 优化前 | 优化后 |
|------|--------|--------|
| 是否有图标 | ❌ 无 | ✅ 有 |
| 图标颜色 | - | 使用 Lumo 语义化颜色 |
| 视觉效果 | 单调 | 丰富、直观 |

### 代码量

| 项目 | 优化前 | 优化后 |
|------|--------|--------|
| 卡片代码 | 每个卡片 8 行 × 4 = 32 行 | 每个卡片 1 行调用 × 4 = 4 行 |
| 重复代码 | 高（4 个几乎相同的 div） | 低（复用 createStatCard 方法） |
| 可维护性 | 低 | 高 |
