================================================================================
                              快速启动步骤
================================================================================

1. 初始化数据库
   mysql -u root -p < db-init.sql
   mysql -u root -p < db-init-data.sql

2. 配置数据库密码
   编辑 src/main/resources/application.yml
   修改 spring.datasource.password 为你的 MySQL 密码

3. 启动项目
   Windows: start.bat
   Linux/Mac: ./start.sh
   或者: ./gradlew bootRun

4. 访问系统
   浏览器打开: http://localhost:8080
   默认账号: admin / admin123

================================================================================
                              注意事项
================================================================================

1. 首次启动需要等待 3-5 分钟，Vaadin 会下载和编译前端资源
2. 确保 MySQL 服务已启动
3. 确保 8080 端口未被占用
4. JDK 版本必须是 17 或更高
5. 密码使用 MD5 加密存储
6. 所有删除操作都有确认对话框
7. 操作日志会自动记录

================================================================================
                              常见问题
================================================================================

Q: 启动后页面空白？
A: 首次启动需要等待前端资源编译，请耐心等待 3-5 分钟。

Q: 登录失败？
A: 确认是否执行了 db-init-data.sql，默认密码是 admin123。

Q: 端口被占用？
A: 修改 application.yml 中的 server.port 配置。

Q: 数据库连接失败？
A: 检查 MySQL 服务是否启动，配置是否正确。
