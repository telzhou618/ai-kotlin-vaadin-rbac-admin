# Dashboard 主题适配测试指南

## 测试目标

验证 Dashboard 页面在明暗主题切换时的视觉效果和功能正常性。

## 测试环境

- 浏览器：Chrome/Firefox/Edge/Safari
- 分辨率：1920x1080（推荐）
- 测试账号：admin/admin123

## 测试步骤

### 1. 亮色模式测试

#### 1.1 登录并查看 Dashboard
```
步骤：
1. 启动项目：gradlew.bat bootRun
2. 访问：http://localhost:8080
3. 登录：admin/admin123
4. 自动跳转到 Dashboard 页面
```

#### 1.2 检查统计卡片
```
检查项：
□ 4 个统计卡片横向排列
□ 卡片背景为浅灰色（不是彩色）
□ 卡片有圆角
□ 卡片内边距适中
□ 标题文字为灰色小字
□ 数值为大号黑色字体
□ 每个卡片右上角有图标
```

#### 1.3 检查图标
```
检查项：
□ 用户总数：蓝色用户图标 👤
□ 角色总数：绿色群组图标 👥
□ 权限节点数：灰色锁图标 🔒
□ 日志总数：红色记录图标 📋
□ 图标大小适中
□ 图标颜色鲜明
```

#### 1.4 检查表格
```
检查项：
□ 表格标题"最近操作日志"清晰可见
□ 表格有 8 列（用户、模块、操作等）
□ 表格列宽自动适配内容
□ 表格文字清晰可读
□ 表格行悬停有高亮效果
```

### 2. 暗色模式测试

#### 2.1 切换到暗色模式
```
步骤：
1. 点击顶部导航栏的主题切换按钮（月亮图标）
2. 页面立即切换到暗色模式
3. 按钮图标变为太阳图标
```

#### 2.2 检查统计卡片
```
检查项：
□ 卡片背景变为深灰色（不是浅色）
□ 卡片与页面背景有明显区分
□ 标题文字为浅灰色
□ 数值为白色/浅色
□ 文字清晰可读，对比度良好
□ 圆角和内边距保持不变
```

#### 2.3 检查图标
```
检查项：
□ 用户总数：亮蓝色图标（比亮色模式更亮）
□ 角色总数：亮绿色图标
□ 权限节点数：浅灰色图标
□ 日志总数：亮红色图标
□ 图标在深色背景下清晰可见
□ 图标颜色自动调整亮度
```

#### 2.4 检查表格
```
检查项：
□ 表格背景为深色
□ 表格文字为浅色
□ 表格边框为深灰色
□ 表格行悬停效果正常
□ 所有文字清晰可读
```

### 3. 主题切换测试

#### 3.1 快速切换
```
步骤：
1. 在 Dashboard 页面
2. 快速点击主题切换按钮 5 次
3. 观察页面变化
```

```
检查项：
□ 每次点击都能立即切换
□ 无延迟或卡顿
□ 无闪烁现象
□ 卡片颜色平滑过渡
□ 图标颜色同步更新
```

#### 3.2 页面刷新
```
步骤：
1. 切换到暗色模式
2. 按 F5 刷新页面
3. 观察页面状态
```

```
检查项：
□ 页面仍然是暗色模式
□ Dashboard 卡片正确显示
□ 图标颜色正确
□ 表格样式正确
```

### 4. 视觉对比测试

#### 4.1 卡片背景对比
```
亮色模式：
- 背景应该是浅灰色（接近白色）
- 与页面背景有轻微区分
- 不应该是彩色（蓝、紫、绿、橙）

暗色模式：
- 背景应该是深灰色（比页面背景稍亮）
- 与页面背景有明显区分
- 不应该是浅色
```

#### 4.2 文字对比度测试
```
使用浏览器开发者工具：
1. 右键点击卡片标题
2. 选择"检查"
3. 查看 Computed 样式
4. 检查 color 和 background-color
5. 计算对比度（应 ≥ 4.5:1）
```

```
检查项：
□ 亮色模式对比度 ≥ 4.5:1
□ 暗色模式对比度 ≥ 4.5:1
□ 符合 WCAG 2.1 AA 标准
```

### 5. 响应式测试

#### 5.1 窗口缩放
```
步骤：
1. 调整浏览器窗口宽度
2. 从 1920px 缩小到 1280px
3. 观察卡片布局
```

```
检查项：
□ 4 个卡片保持横向排列
□ 卡片宽度自动调整
□ 文字不换行或溢出
□ 图标位置正确
```

#### 5.2 浏览器缩放
```
步骤：
1. 按 Ctrl + + 放大页面
2. 按 Ctrl + - 缩小页面
3. 按 Ctrl + 0 恢复默认
```

```
检查项：
□ 卡片布局保持正常
□ 文字大小按比例缩放
□ 图标大小按比例缩放
□ 无布局错乱
```
